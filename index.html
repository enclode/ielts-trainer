Как пользоваться

  1. Нажмите «Новый тест», выберите модуль (Listening, Reading или Writing).
  2. Загрузите PDF с заданиями и укажите страницы нужного теста.
  3. Загрузите PDF с ответами — программа сама найдёт ответы. Проверьте ключ и при необходимости исправьте.
  4. Для Listening добавьте аудиофайлы (mp3) по порядку частей.
  5. Сохраните тест — он останется в библиотеке на этом компьютере. Кнопкой «В файл» его можно перенести на другой компьютер.
  6. Ученик нажимает «Начать», вводит имя и решает. После сдачи — балл, band и разбор ошибок.

Выделять текст маркером можно, если PDF текстовый (не скан): выделите мышью фрагмент и нажмите «Highlight».

3. Ответы (ключ)

Страницы с по
Как записывать ключ
  • 3 library / the library — несколько верных вариантов через «/».
  • 4 (car) park — слово в скобках можно писать, а можно нет.
  • 14-15 B, D — «выберите две буквы», порядок любой.
  • 20 F [A-H] — в [квадратных скобках] какие буквы показать ученику.
  • TRUE/FALSE/NOT GIVEN и YES/NO/NOT GIVEN ученик выбирает кнопками, буквы — тоже кнопками, остальное вписывает.

Для Writing ключа нет: этот PDF (образцы ответов, если есть) откроется ученику после сдачи, чтобы сравнить со своим текстом.
