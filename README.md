# Компьютерный IELTS — тренажёр

Программа для подготовки к IELTS в компьютерном формате (computer-delivered IELTS).
Учитель загружает PDF с заданиями, PDF с ответами и аудио — ученик решает тест
на экране, похожем на настоящий экзамен, и сразу получает результат и band.

## Как открыть

- **По ссылке** (если включены GitHub Pages): `https://enclode.github.io/ielts-trainer/`
- **Файлом**: скачать `index.html` и открыть двойным щелчком в Chrome или Edge.

При открытии нужен интернет: программа для показа PDF (pdf.js) загружается из сети.

## Что умеет

- **Интерфейс на трёх языках** — узбекский (по умолчанию), английский и русский, переключатель вверху справа. Экран самого экзамена всегда на английском, как на настоящем IELTS.
- **Listening, Reading, Writing.** Speaking на компьютерном IELTS сдаётся вживую, его здесь нет.
- Экран повторяет официальный пробный компьютерный IELTS: чёрная полоса со временем,
  кнопки Help и Hide, номера вопросов внизу (отвеченные — белые, «Review» — кружок),
  стрелки, вступительные экраны (данные кандидата, проверка звука, инструкции).
- В готовых тестах Listening задание показано прямо на экране, как на экзамене:
  пропуски с номером внутри, выбор ответа кружками, перетаскивание слов, таблица A/B/C.
  Тесты, которые учитель создаёт из своего PDF, показываются в два окна: PDF и ответы.
- Listening: запись играет один раз, затем 2 минуты на проверку, тест сдаётся сам.
  Есть режим «Тренировка» — без ограничения времени и с удобным плеером: перемотка
  на 3 и 10 секунд, полоса прокрутки, скорость 0.75×–1.25×, горячие клавиши.
  В разборе после сдачи запись можно переслушать тем же плеером.
- **Полный mock:** Listening → Reading → Writing подряд, как в день экзамена, с одним
  номером кандидата. Listening можно собрать из частей (например, Section 1 + Section 2
  из разных тестов). В конце — общий результат: баллы, оценка Writing, Speaking от
  учителя и Overall. Можно продолжить после перезагрузки.
- Ответы в PDF с ключами программа находит сама; ключ можно поправить руками.
- После сдачи: band, ошибки по частям и типам заданий, разбор прямо в тесте.
  Writing — подсчёт слов и оценка учителя по четырём критериям.
- Библиотека тестов, история результатов (выгрузка в Excel), перенос теста
  на другой компьютер одним файлом. Можно загрузить сразу много тестов — в том числе
  архивом .zip, без распаковки.

## Где хранятся данные

Тесты (PDF, аудио, ключи) и результаты учеников хранятся **только в браузере того
компьютера**, где их загрузили. На GitHub и в интернет они не отправляются.
Чтобы перенести тест на другой компьютер — кнопка «В файл», а там «Загрузить тест из файла».

## Важно

Не кладите в этот репозиторий PDF и аудио из книг (Cambridge и др.): репозиторий
открытый, а у материалов есть авторские права.
