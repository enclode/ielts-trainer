# ielts-trainer — правила проекта

Тренажёр компьютерного IELTS. Пользователи — преподаватели, **не программисты**.
Отвечай по-русски, простыми словами. Комментарии в коде и сообщения коммитов — по-русски.
Техническую часть (код, проверки, коммит, пуш) делай сам.

## Устройство

- Вся программа — один файл `index.html` (HTML + CSS + JS, без сборки).
- PDF показывает pdf.js **3.11.174** (UMD, cdnjs, запасной — jsdelivr). Не обновлять
  на 4.x без переделки: там другой способ подключения.
- Тесты хранятся в IndexedDB браузера (`ielts-cd-trainer`), история и незаконченная
  попытка — в localStorage. Сервера нет.
- Репозиторий публичный, сайт — GitHub Pages из `main`: пуш в `main` сразу меняет
  то, что открывают ученики.

## Как проверять

Тесты пишутся во временную папку сессии, в репозитории их нет.
- Синтаксис: вытащить JS из `index.html` и `node --check`.
- Настоящий интерфейс: Playwright (`require('playwright')`, браузер предустановлен).
  Запросы к cdnjs подменять через `context.route` на локальный
  `pdfjs-dist@3.11.174` (`npm i pdfjs-dist@3.11.174`) — в песочнице cdnjs закрыт.
- Пробные материалы делать самим: HTML → PDF через `page.pdf()`, аудио — wav из Python.
- Проверять сценарии целиком: создание теста, поиск ответов в PDF, решение, сдача,
  перезагрузка посреди теста (продолжение), Listening с аудио, Writing, «В файл» / импорт.

## Чего не делать

- Не класть в репозиторий PDF и аудио из книг (авторские права, репозиторий открытый).
- Не ломать формат сохранённых тестов и файла экспорта (`format: 'ielts-cd-trainer'`):
  у учителей уже могут быть сохранённые тесты.
